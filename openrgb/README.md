# OpenRGB controller (work in progress)

`LenovoLegionGPUController/` is an OpenRGB controller for the Lenovo Legion RTX 5080 light chip
(I2C `0x92` through NvAPI, same protocol as described in the main README).

It is drop-in source for OpenRGB's `Controllers/` folder. It is kept here for review and a manual rewrite,
and is not being submitted upstream.
